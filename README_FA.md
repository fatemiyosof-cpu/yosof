# ARcodm Subscription ULTRA

نسخه‌ی ULTRA پرزرق‌وبرق و سبک با Intro کوتاه ARcodm و ورود مخصوص موبایل صفحه Subscription با استایل ARcodm، انیمیشن‌های CSS، فونت Lalezar، نمایش حجم/اعتبار/لوکیشن، دانلود تکی `.conf`، دانلود ZIP و کپی لینک.

## Render
Build Command:
`npm install`

Start Command:
`node server.js`

Health:
`/health`

صفحه Subscription:
`/sub/ID`
